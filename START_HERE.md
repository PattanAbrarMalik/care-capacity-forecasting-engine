# Start here

This is the revised **Data Science internship submission**, with code and supporting evidence.

1. Open **reports/Internship_Report.docx** to see the project purpose, methodology, results and limitations.
2. Read **README.md** for installation. On Windows with Python 3.11 or 3.12 installed, you can also double-click **START_WINDOWS.bat**.
3. Open **http://127.0.0.1:8501** after the server starts.
4. Review **notebooks/01_research_workflow.ipynb** for the executed analytical steps.
5. Use **docs/VIVA_GUIDE.md** and **docs/CODE_WALKTHROUGH.md** to prepare your explanation.

The strongest result to explain: a local trend selected on validation data achieved **21.91 children test MAE**, versus **31.22** for persistence, on **99 exact seven-day target pairs**. That is **29.82% lower holdout MAE**, not classification accuracy.

The contribution is an auditable end-to-end analysis: source quality, calendar-aware metrics, explicit assumptions, baseline comparison, leakage prevention, and a working application that exposes the evidence.
